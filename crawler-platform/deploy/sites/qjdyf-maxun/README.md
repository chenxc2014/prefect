# 千金供应商系统：商品流向（Maxun）

`template.json` 是 Linux 169 上已发布的固定模板引用，机器人草稿由 Maxun 在线设计器录制，平台另存发布副本并校验流程摘要。它不是可脱离 Maxun 数据库单独运行的浏览器脚本。迁移到另一个 Maxun 实例时，应迁移机器人及配置或重新发布，不能直接沿用旧实例的机器人 UUID。

当前验证范围为 2026-11-12 单日。运行参数使用 `begindate`、`enddate`，网站账号通过 `qjdyf-test` 引用，在执行节点受限配置中注入。模板不含账号密码，也不包含一次性验证码。

操作入口：采集管理平台 → 已发布任务 → 千金 · 商品流向（Maxun）→ 填写日期和账号引用 → 运行。Prefect 负责投递与状态，Maxun 执行网站操作，平台检查并归档原始 XLSX。当前没有启用定时任务。

登录使用图片验证码识别；验证码错误最多重试三次，账号或权限错误停止重试。日期输入采用真实录制到的 iframe 路径，直接设置日期值。下载同时监听浏览器事件和网页创建的 Blob，保留网站生成的原始文件字节。

完整操作、验证结果及限制见 `doc/千金商品流向Maxun操作说明.html`、`doc/千金商品流向Maxun验收.json`。原 EasySpider 同站模板仍保留，两种模板互相独立；没有修改原 fetch-crawler 公共框架。

验证中部分重复导出未返回文件，根因尚未完全确认。最终成功使用浏览器下载事件；Blob 与网络响应降级路径已通过受控浏览器测试。本次单日通过不代表长期无人值守或短时间重复导出的稳定性已完成验收。
