# 老百姓供应商平台配送数据（Maxun）

在采集管理平台选择「已发布任务 → 业务采集 → 老百姓 · 配送数据（Maxun）」，填写起止日期和账号引用 `lbx-delivery`，然后点击「运行」。日期格式为 `YYYY-MM-DD`，账号由 Linux 169 执行节点在运行时注入。

Maxun 登录供应商协同平台，从「流向平台 → 配送数据」查询并导出，再从下载中心获取本次生成的原始 Excel。平台校验商品编码、出入库日期、出入库数量以及日期范围，文件可在对应运行详情中下载。

`template.json` 保存当前固定版本所引用的 Maxun 机器人和流程摘要。移到其他 Maxun 实例时需重新创建关联和发布。查询范围由供应商账号权限决定，当前任务使用手动运行。
