Maxun 在线设计

在 Web 中录制网站，在这里发布固定版本并交给 Prefect 执行。

在线设计并发布新网站

先打开设计器创建「录制模式」机器人，保存后回到这里刷新列表。

进入在线可视化设计器
已接入统一登录登录采集管理平台后，进入 Maxun 无需再次输入邮箱和密码。保存机器人后，返回这里发布并交给 Prefect 调度。

同一业务的不同引擎请填写相同的所属任务名称，列表将自动归组。用途按使用目的选择，不以是否生成真实文件判断。

登录验证码重试与原始文件下载

步骤选自当前真实录制；图片和提示选择器请从兼容视图或实际网页核对。

表格提取：Data/result.csv；原始文件导出：Data/downloads/*.xlsx。多项规则请分行填写，必须实际生成并通过校验。

从设计到执行

  1. 打开在线设计器新建机器人，输入真实网站地址，选择 Recorder Mode（录制模式）。
  2. 录制并保存完成登录、筛选、查询及提取或导出流程，保存机器人。
  3. 绑定参数并发布刷新机器人列表，绑定日期和验证码步骤，设置文件成功条件。
  4. 运行与检查结果在「已发布任务」填写参数提交运行，通过 Prefect 查看日志并下载产物。

导入与发布 EasySpider 任务

导入设计器保存的原生 JSON，可调整实际节点的选择器与输入值；循环、分支等复杂结构保留原配置。

同一业务的不同引擎请填写相同的所属任务名称，列表将自动归组。用途按使用目的选择，不以是否生成真实文件判断。

输入值使用 {{begindate}}、{{enddate}} 声明运行参数；账号节点可使用 {{secret.username}}、{{secret.password}}，执行时从受限配置读取。请勿将真实密码写入模板。

与 Maxun 如何选择？

  1. 已有 EasySpider 模板继续导入运行，修改流程时回到独立客户端。
  2. 希望全部在网页中设计使用 Maxun，并验证目标网站的登录、查询和导出能力。
  3. 任务互不转换同一网站可分别制作两套流程，但模板不能直接互导。
日常服务器执行无需保持本地设计器运行。

接入后如何运行

  1. 登记原有采集类配置模块、类名与原构造参数，不重写公共框架。
  2. 验证独立执行环境复用原依赖、浏览器与下载机制，确认任务间文件和账号隔离。
  3. 注册 Prefect 任务将已验证的入口绑定执行节点，配置并发、超时与重试。
  4. 统一监控与结果检查保留原业务成功语义，再接入日志与产物归档。

架构与引擎关系

一套工作台，三种执行路径

EasySpider：客户端导出 JSON
fetch-crawler：现有 Python 采集类
