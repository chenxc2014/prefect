实现与兼容边界

  • 统一会话由采集管理 API 管理。浏览器仅保存 Secure、HttpOnly、SameSite=Lax 的随机会话 Cookie；平台密码不进入 URL 或 localStorage。
  • Nginx 对 Prefect 浏览器请求检查统一会话，再在服务端转发原有 API 认证；Prefect 后端认证保持开启。Worker 的 Basic 接口认证继续保留，不要求执行节点使用浏览器会话。
  • Maxun 通过服务端登录衔接获取原生 Cookie，并初始化其界面用户状态；公开入口由统一会话保护。仅访问 9443 且未登录时也会返回统一登录页。
  • 会话写请求校验来源与 CSRF，登录失败进行限速；SQLite 仅保存会话令牌摘要，支持到期与退出撤销。当前仍为单开发账号模式，尚未建设企业身份源及多用户角色权限。
  • SSO Cookie 不区分端口。日常请使用同一台 169 的内网 IP 地址访问两个端口，避免混用不同域名、IP 或不同浏览器配置。证书与防火墙来源白名单要求继续沿用。
